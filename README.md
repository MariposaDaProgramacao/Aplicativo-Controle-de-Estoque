📦 BoxStock
Aplicativo de controle de estoque desenvolvido com Flutter e Firebase.

Funcionalidades
✅ Autenticação (Login/Cadastro/Logout)

✅ Dashboard com resumo do estoque

✅ CRUD de produtos

✅ Entrada e Saída de produtos

✅ Histórico de movimentações

✅ Busca por nome/código

✅ Design exclusivo "Caixa de Papelão"

Tecnologias
Flutter & Dart

Firebase Authentication

Cloud Firestore
